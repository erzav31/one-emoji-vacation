Entry for the make.fun competition "One Emoji, One Dream Vacation": a program
that writes exactly one emoji to `/output/entry.txt`. The emoji is the
campsite — a tent pitched where the road ends and the stars begin. No beach,
no resort, no crowd: one night under an open sky is the whole dream, and the
tent says it in a single picture.

## Run it

```sh
node main.ts
```

This writes the emoji to `/output/entry.txt` (no trailing newline).
